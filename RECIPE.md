# Agora Real Estate Follow-Up Assistant Demo

## 1. Overview

Explore fictional Austin rentals, compare housing preferences and walk through a simulated viewing. All listings, addresses, rents and viewing slots are fictional public demonstration material. No live property search, CRM, calendar, outbound dialer, saved lead, screening decision, payment or actual viewing is connected. Do not claim a real booking, submitted request or promised callback. Match only stated housing preferences; do not discriminate, steer by protected characteristics, or infer eligibility. Unconfigured charges, lease terms and availability remain unknown. Keep corrections and confirmations only within this conversation.

## 2. Try the Demo

Use [local setup](https://github.com/AgoraIO-Community/agora-rental-follow-up-demo/blob/main/README.md#run-it). Choose `Start rental inquiry`, allow microphone access and try: “I am looking for a two-bedroom rental in Austin under USD 2,000 per month. Can we discuss a viewing?” Ask for a verbal recap before ending. Each session ends after ten minutes. No real outbound phone call is placed.

## 3. Architecture & Tech Stack

Next.js, React, TypeScript, Agora Conversational AI, Agents SDK, RTC and RTM. The existing browser voice lifecycle is unchanged. Next.js signs tokens and starts/stops the managed Agent; no business database or external action is connected.

## 4. Prerequisites & Configuration

Use Node.js 24, pnpm 9.15.9 and an Agora project with Conversational AI enabled. Create `.env.local` from `env.local.example` only when absent. Set public `NEXT_PUBLIC_AGORA_APP_ID` at build/runtime and server-only `NEXT_AGORA_APP_CERTIFICATE`. Never expose the certificate in browser code. The default managed models need no separate vendor key.

## 5. Quick Start

```bash
pnpm install --frozen-lockfile
pnpm run doctor
pnpm run dev
```

Open http://localhost:3000. Preserve existing credentials. The planned npm creator is `npx agora-rental-follow-up-demo@latest my-app`; a published version can differ from this local source.

## 6. How It Works

The start action fetches a combined RTC/RTM token and invites the Agent using requester_id and channel_name. Instructions are generated by `lib/agent-config.ts`. Tools remain disabled. Corrected details and simulation outcomes exist only in the current conversation; there is no saved result or cross-session memory.

## 7. Customize for Your Business

Edit `lib/agent-config.ts` for the role, workflow and guardrails, `lib/scenario-knowledge.ts` for fictional reference and generated dates, `lib/presentation.ts` for public identity, and `components/ScenarioFaq.tsx` for usage answers. `lib/runtime-profile.ts` owns model and voice defaults. Existing repository, npm package and Recipe identifiers remain stable.

## 8. Deployment & Validation

Follow [deployment instructions](https://github.com/AgoraIO-Community/agora-rental-follow-up-demo/blob/main/README.md#deployment). Run `pnpm run verify`; Docker checks use `pnpm run verify:docker` separately. Inspect desktop/mobile pages, FAQ, and inline startup failure/retry. Synthetic tests and builds do not establish real model behavior, bilingual speech quality, hosted connectivity or actual business operations. Real speech acceptance is separate. No publication or deployment is performed by this source update.
